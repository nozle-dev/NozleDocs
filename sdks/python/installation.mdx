`nozle-sdk` supports Python 3.9 through 3.13, uses `requests`, and includes a `py.typed` marker.

Entity subscription APIs are introduced in `0.5.0`.

```bash
pip install nozle-sdk==0.11.0
```

<Info>
Version `0.11.0` sends Feature Events through the Go Engine endpoint. Version `0.10.0` adds `NozleAPIError.code` and `has_code()`, richer checkout result types, and no longer requires `feature` in `check_and_deduct()`. Version `0.9.1` fixes Feature Event timestamp serialization, including events created by the OpenAI and Anthropic wrappers. Version `0.9.0` introduced subscription options, signed quotes, pending-change withdrawal, and scoped checkout recovery. See [subscription self-service](/sdks/python/billing#subscription-self-service) and the [release notes](/changelog#razorpay-and-stripe-guides-new-sdk-releases-api-fixes).
</Info>

## Create a client

```python
import os

from nozle import Nozle

nozle = Nozle(
    api_key=os.environ["NOZLE_SECRET_KEY"],
    timeout=10,
)
```

| Argument | Type | Default | Description |
|---|---|---|---|
| `api_key` | `str` | required | Organization credential. Protected operations require `sk_`. |
| `host` | `str` | `https://api.nozle.app` | Keyword-only. Root API origin. The SDK sends Engine calls to `{host}/engine` and Core calls to `{host}/core`. Set only this for a local or self-hosted deployment behind one reverse proxy. |
| `base_url` | `str` | `https://api.nozle.app/engine` | Engine API origin for `track()`, entitlements, credits, Entities, usage, and margin. Overrides the address derived from `host`. |
| `events_url` | `str` | `https://api.nozle.app/core` | Core API origin for customer writes, billing resources, subscription discovery, credit-system discovery, and Entity subscriptions. Use `https://api.nozle.app/core` in production. Overrides the address derived from `host`. |
| `timeout` | `float` | `10` | Per-request timeout in seconds. |

The client defaults to the public service bases under `https://api.nozle.app`. For a local or self-hosted deployment behind one proxy, set `host`. Set `base_url` or `events_url` only when the two services live at unrelated addresses; each one you set wins over `host`. If you set only one of them, the other service still uses `host` (by default production), so set `host` too. Trailing slashes are removed automatically.

```mermaid
flowchart LR
  App[Python backend] --> SDK[nozle-sdk]
  SDK -->|base_url| API[Event ingestion, entitlements, credits, usage, margin]
  SDK -->|events_url| Core[Customers, billing resources, subscription discovery]
```

## Manage the HTTP session

The client is synchronous and owns a reusable `requests.Session`. Use it as a context manager when its lifetime is scoped:

```python
from nozle import Nozle

with Nozle(
    api_key=os.environ["NOZLE_SECRET_KEY"],
    base_url="https://api.nozle.app/engine",
    events_url="https://api.nozle.app/core",
) as nozle:
    health = nozle.ping()
```

For an application-wide singleton, call `nozle.close()` during shutdown.

## Authentication model

- `plans()` accepts either a publishable `pk_` or secret `sk_` key.
- Every customer, event, checkout, subscription, credit, Entity, usage, entitlement, health, and margin operation requires `sk_`.
- Wrong key types fail locally with `NozleAuthenticationError` before network I/O.

<Warning>
This is a backend SDK. Never expose an `sk_`, master key, or internal credential to browser or mobile code.
</Warning>

## API surface

| Area | Methods |
|---|---|
| API | `ping()`, `plans()`, `track()`, `can()` |
| Billing | `checkout()`, `checkout_status()`, `verify_checkout()`, `checkout_invoice()`, `subscribe()`, `cancel_subscription()`, `subscription_options()`, `preview_subscription_change()`, `withdraw_pending_subscription_change()`, `preview_subscription_transition()`, `apply_subscription_transition()` |
| Customers | `customers.upsert()` |
| Credit systems | `credit_systems.list()` |
| Entities | `get()`, `list()`, `upsert()`, `activate()`, `suspend()`, `bulk_upsert()` |
| Entity subscriptions | `ensure()`, `get()`, `list()`, `checkout()`, `checkout_many()`, `change_plan()`, `cancel()`, `remove()` |
| Credits | Customer and Entity balance/history reads, `allocate()`, `deallocate()` |
| Usage | Advisory `check()` and atomic `track()` |
| Cost events | `cost_events.track()` |
| Margin | `summary()`, `by_customer()`, `by_metric()`, `by_plan()`, `by_model()`, `trend()` |
| LLMs | `wrap_openai()`, `wrap_anthropic()` |

`check_and_deduct(customer_id, credits=5)` remains available for the legacy wallet path. The `feature` argument is deprecated and ignored.

## Transport behavior

- The SDK does not automatically retry requests.
- Mutations therefore execute at most once per SDK call.
- Connection and timeout failures raise `NozleTransportError`.
- Non-2xx responses raise structured `NozleAPIError`.
- Sensitive values in API error payloads are redacted.

See [Errors and retries](/sdks/python/errors) for handling guidance.

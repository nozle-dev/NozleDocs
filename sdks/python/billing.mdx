

## Invoices

```python
page = nozle.invoices.list("cus_123", status="finalized", page=1)    # {"invoices", "meta"}
invoice = nozle.invoices.get(page["invoices"][0]["nozle_id"])
pdf = nozle.invoices.download_url(invoice["nozle_id"])               # str or None
upcoming = nozle.invoices.preview("cus_123", subscription_ids=["sub_1"])
```

`preview` with `plan_code` instead of `subscription_ids` shows the first invoice of a new subscription. Pay an open invoice with `checkout_invoice`.

A PDF is generated the first time it is asked for, so the download call returns no URL until it exists; ask again a few seconds later, or wait for the `invoice.generated` webhook. Invoice preview is a premium feature of the organization (`422 premium_integration_missing` otherwise).

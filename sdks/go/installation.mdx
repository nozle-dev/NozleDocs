---
title: "Installation"
description: "Configure the server-side Nozle Go SDK."
---

The Go SDK requires Go 1.22 or later. Install it after the public repository is published:

```bash
go get github.com/nozle-dev/nozle-go
```

```go
import nozle "github.com/nozle-dev/nozle-go"

client := nozle.New("sk_your_secret_key")
```

The default Engine and Core URLs are `https://api.nozle.app/engine` and `https://api.nozle.app/core`. For a local deployment:

```go
client := nozle.New("sk_local", nozle.WithBaseURL("http://localhost:8080"), nozle.WithEventsURL("http://localhost:3000"))
```

`WithTimeout` changes the 10-second request timeout. `WithHTTPClient` injects an `*http.Client`. All methods accept `context.Context`. Reuse one client and keep `sk_` credentials on your server.

The SDK makes one HTTP attempt per request. It never retries mutations automatically. For uncertain idempotent operations, retry with the same key and payload.

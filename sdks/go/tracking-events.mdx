---
title: "Tracking events"
description: "Send Core metered events with stable transaction IDs."
---

```go
err := client.Track(ctx, nozle.TrackParams{
  CustomerID: "workspace_123", Event: "api_calls",
  SubscriptionID: "workspace_123_subscription",
  TransactionID: "request_0183f",
  Metadata: map[string]any{"tokens": 1500},
})
_ = err
```

`Track` posts `{ "event": { ... } }` to Core `/api/v1/events`. If `SubscriptionID` is omitted, the SDK looks up active subscriptions and requires exactly one. Supply it explicitly when a customer has multiple active subscriptions. Reuse the same transaction ID and timestamp when retrying a logical event. `Meter` posts a batch of 1–1000 events to Core `/api/v1/events/batch`; each batch event needs an explicit subscription ID.

`TrackCostEvent` records a Cost Event in Engine. Set `CostMeterCode` and either `ParentTransactionID` or `ExternalCustomerID`. Supply a stable `CostEventID` for retries.

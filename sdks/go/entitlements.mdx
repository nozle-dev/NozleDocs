```go
result, err := client.Can(ctx, "workspace_123", "agent_execution")
if err == nil && result.Allowed {
  // Run the permitted operation.

```

`Can` reads Engine `/api/v1/can`. For credit-backed features, `CheckUsage` provides an advisory projection and `TrackUsage` enforces and records the deduction atomically.

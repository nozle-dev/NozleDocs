---
title: "LLM usage capture"
description: "Record OpenAI and Anthropic usage after a provider call."
---

Call the provider normally, then pass its usage metadata to the SDK. This keeps the Go SDK independent of provider client versions and never sends prompt or completion text.

```go
err := client.CaptureOpenAIUsage(ctx, nozle.ProviderCapture{
  CustomerID: "workspace_123", SubscriptionID: "workspace_123_subscription",
  FeatureCode: "llm_tokens", CostMeterCode: "ai_tokens",
  Model: "example-chat-model", TransactionID: "generation-0183f",
}, nozle.OpenAIUsage{PromptTokens: 320, CompletionTokens: 84, CachedInputTokens: 20})
_ = err
```

`CaptureAnthropicUsage` accepts `AnthropicUsage` with input, cached input, cache write, and output token counts. Both methods emit a Feature Event and, when `CostMeterCode` is set, categorized Cost Events linked by the parent transaction ID. They return telemetry errors to the caller; handle those errors without replacing a successful provider response. Use a stable transaction ID for retries.

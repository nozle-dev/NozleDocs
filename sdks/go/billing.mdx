

## Invoices

```go
page, err := client.ListInvoices(ctx, "cus_123", nozle.ListInvoicesParams{Status: "finalized", Page: 1})
invoice, err := client.GetInvoice(ctx, page.Invoices[0].NozleID)
pdf, err := client.InvoiceDownloadURL(ctx, invoice.NozleID)    // "" until the PDF exists
next, err := client.PreviewInvoice(ctx, nozle.PreviewInvoiceParams{CustomerID: "cus_123", SubscriptionIDs: []string{"sub_1"}})
```

`PlanCode` instead of `SubscriptionIDs` shows the first invoice of a new subscription. Pay an open invoice with `CheckoutInvoice`.

A PDF is generated the first time it is asked for, so the download call returns no URL until it exists; ask again a few seconds later, or wait for the `invoice.generated` webhook. Invoice preview is a premium feature of the organization (`422 premium_integration_missing` otherwise).

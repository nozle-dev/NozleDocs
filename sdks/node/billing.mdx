

## Invoices

```ts
const page = await nozle.invoices.list('cus_123', { status: 'finalized', page: 1 })   // { invoices, meta }
const invoice = await nozle.invoices.get(page.invoices[0].nozle_id)
const pdf = await nozle.invoices.downloadUrl(invoice.nozle_id)                        // string or null
const next = await nozle.invoices.preview({ customerId: 'cus_123', subscriptionIds: ['sub_1'] })
```

`preview` with `planCode` instead of `subscriptionIds` shows the first invoice of a new subscription. Pay an open invoice with `checkoutInvoice`.

A PDF is generated the first time it is asked for, so the download call returns no URL until it exists; ask again a few seconds later, or wait for the `invoice.generated` webhook. Invoice preview is a premium feature of the organization (`422 premium_integration_missing` otherwise).

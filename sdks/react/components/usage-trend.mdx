`UsageTrend` draws one bar per past billing period, oldest first, labelled with the period's start date and its amount or units.

## What UsageTrend supports

- The amount of each period, or with `featureCode` the units of one feature (zero where a period has none).
- Periods in any order; they are sorted by start date.
- Loading, error and empty states.

## Where to use UsageTrend

- A usage history section of your billing settings.
- Beside [`UsageBreakdown`](/sdks/react/components/usage-breakdown) to compare this period with earlier ones.

## Importing UsageTrend

```tsx
import { UsageTrend, type CustomerUsageData } from '@nozle-js/react'
```

## Rendering UsageTrend

```tsx
import { UsageTrend, type CustomerUsageData } from '@nozle-js/react'

const period = (from: string, to: string, apiCalls: number): CustomerUsageData => ({
  from_datetime: from,
  to_datetime: to,
  currency: 'USD',
  amount_cents: Math.round(apiCalls * 0.04),
  charges_usage: [
    {
      units: String(apiCalls),
      amount_cents: Math.round(apiCalls * 0.04),
      amount_currency: 'USD',
      charge: { nozle_id: `chg_${from}`, charge_model: 'standard' },
      feature: { nozle_id: 'ftr_api', code: 'api_calls', name: 'API calls' },
    },
  ],
})

const periods: CustomerUsageData[] = [
  period('2026-07-01T00:00:00Z', '2026-07-31T23:59:59Z', 22100),
  period('2026-08-01T00:00:00Z', '2026-08-31T23:59:59Z', 26400),
  period('2026-09-01T00:00:00Z', '2026-09-30T23:59:59Z', 29800),
]

export function History() {
  return (
    <>
      <UsageTrend periods={periods} />
      <UsageTrend periods={periods} featureCode="api_calls" />
    </>
  )
}
```

## Using live data

[`useUsage({ period: 'past' })`](/sdks/react/hooks#the-hooks) reads past periods for the signed-in customer through your `billingEndpoint`; `periods` sets how many.

```tsx
import { UsageTrend, useUsage, type CustomerUsageData } from '@nozle-js/react'

export function LiveTrend() {
  const { data, isPending, error } = useUsage({ period: 'past', periods: 6 })
  // With `period: 'past'` the data is the list of periods.
  return <UsageTrend periods={data as CustomerUsageData[] | undefined} isLoading={isPending} error={error} />
}
```

Without the hooks, read `GET https://api.nozle.app/core/api/v1/customers/{external_customer_id}/past_usage` on your backend with a secret key and pass its `usage_periods`. It takes `periods_count` and `feature_code`.

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `periods` | `CustomerUsageData[]` or `null` | none | The periods to chart. Empty or missing shows the empty message. |
| `featureCode` | `string` | none | Charts the units of this feature instead of the amount. Bars read "29,800 api_calls". |
| `isLoading` | `boolean` | `false` | Shows a loading placeholder. |
| `error` | `Error`, `string` or `null` | `null` | Shows the message as an alert. |
| `emptyMessage` | `string` | `'No past usage yet.'` | Shown when there are no periods. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides. See [Appearance](/sdks/react/styling). |

Bars scale to the largest period; each bar has an accessible label with its date and value. Dates show in UTC in `en-US`.

### Appearance elements

`usageTrend` (root), `usageTrend__bar` (each bar).

`UsageTrend` draws one bar per past billing period, oldest first, labelled with the period's start date and its amount or units.

**When to use**

- A usage history section of your billing settings.
- Beside [`UsageBreakdown`](/sdks/react/components/usage-breakdown) to compare this period with earlier ones.
- A chart of one feature's units over time, with `featureCode`.

## Usage

```tsx
import { UsageTrend, useUsage, type CustomerUsageData } from '@nozle-js/react'
```

Inside a `BillingProvider` with `billingEndpoint`, read past periods with `useUsage({ period: 'past' })` and pass them in:

```tsx app/billing/history/page.tsx
'use client'
import { BillingProvider, UsageTrend, useUsage } from '@nozle-js/react'

function History() {
  const { data, isPending, error } = useUsage({ period: 'past', periods: 6 })
  return <UsageTrend periods={data} isLoading={isPending} error={error} />
}

export default function HistoryPage() {
  return (
    <BillingProvider publishableKey="pk_live_..." billingEndpoint="/api/nozle">
      <History />
    </BillingProvider>
  )
}
```

Periods can come in any order; they are sorted by start date. Bars scale to the largest period, and each bar has an accessible label with its date and value. Dates show in UTC in `en-US`.

## Data

`periods` is a list of `CustomerUsageData`, one per billing period, as in the `usage_periods` of Core's past-usage endpoint. Amounts are in cents; `units` is a decimal string.

```tsx
import { UsageTrend, type CustomerUsageData } from '@nozle-js/react'

const period = (from: string, to: string, apiCalls: number): CustomerUsageData => ({
  from_datetime: from,
  to_datetime: to,
  currency: 'USD',
  amount_cents: Math.round(apiCalls * 0.04),
  charges_usage: [
    {
      units: String(apiCalls),
      amount_cents: Math.round(apiCalls * 0.04),
      amount_currency: 'USD',
      charge: { nozle_id: `chg_${from}`, charge_model: 'standard' },
      feature: { nozle_id: 'ftr_api', code: 'api_calls', name: 'API calls' },
    },
  ],
})

const periods: CustomerUsageData[] = [
  period('2026-08-01T00:00:00Z', '2026-08-31T23:59:59Z', 26400),
  period('2026-09-01T00:00:00Z', '2026-09-30T23:59:59Z', 29800),
]

export function History() {
  return <UsageTrend periods={periods} />
}
```

### Live data

[`useUsage({ period: 'past' })`](/sdks/react/hooks#the-hooks) reads past periods for the signed-in customer through your `billingEndpoint`; `periods` sets how many. Its `data` is the list of periods and passes to `periods` directly:

```tsx
import { UsageTrend, useUsage } from '@nozle-js/react'

export function LiveTrend() {
  const { data, isPending, error } = useUsage({ period: 'past', periods: 6 })
  return <UsageTrend periods={data} isLoading={isPending} error={error} />
}
```

Without the hooks, read `GET https://api.nozle.app/core/api/v1/customers/{external_customer_id}/past_usage` on your backend with a secret key and pass its `usage_periods`. It takes `periods_count` and `feature_code`.

## Examples

### Units of one feature

With `featureCode`, each bar shows that feature's units in the period instead of the amount, for example "29,800 api_calls". Periods without the feature show zero.

<Frame>
  <img src="/images/react/components/usage-trend-feature/light.png" alt="UsageTrend with the API call units of five months, light theme" width="508" />
</Frame>

```tsx
import { UsageTrend, useUsage } from '@nozle-js/react'

export function ApiCallsTrend() {
  const { data, isPending, error } = useUsage({ period: 'past', periods: 6 })
  return <UsageTrend periods={data} featureCode="api_calls" isLoading={isPending} error={error} />
}
```

### Loading, empty and error

`isLoading` shows a loading placeholder, an empty list shows `emptyMessage`, and `error` shows the message as an alert.

<Frame>
  <img src="/images/react/components/usage-trend-states/light.png" alt="UsageTrend loading placeholder, No past usage yet message, and an error message, light theme" width="1008" />
</Frame>

```tsx
import { UsageTrend } from '@nozle-js/react'

export function TrendStates() {
  return (
    <>
      <UsageTrend isLoading />
      <UsageTrend periods={[]} />
      <UsageTrend error="Usage history could not be loaded." />
    </>
  )
}
```

## API reference

<ResponseField name="periods" type="CustomerUsageData[] | null">
  The periods to chart, in any order. Empty or missing shows the empty message.
</ResponseField>

<ResponseField name="featureCode" type="string">
  Charts the units of this feature instead of the amount. Bars read "29,800 api_calls".
</ResponseField>

<ResponseField name="isLoading" type="boolean" default={false}>
  Shows a loading placeholder.
</ResponseField>

<ResponseField name="error" type="Error | string | null">
  Shows the message as an alert. Defaults to `null`.
</ResponseField>

<ResponseField name="emptyMessage" type="string" default="No past usage yet.">
  Shown when there are no periods.
</ResponseField>

<ResponseField name="appearance" type="Appearance">
  Theme, variables and element overrides. Defaults to the provider's. See [Appearance](/sdks/react/styling).
</ResponseField>

### States

| State | What shows |
|---|---|
| `isLoading` | A skeleton placeholder with `role="status"`. |
| `error` set | The message in a `role="alert"` card, in the danger text colour. |
| No periods | `emptyMessage`. |

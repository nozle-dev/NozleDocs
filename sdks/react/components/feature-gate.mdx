---
title: "FeatureGate"
description: "Shows content when the customer has a feature, and a fallback when they do not."
keywords: ["feature gate", "entitlement", "access control", "react"]
---

`FeatureGate` renders its children when `allowed` is true and `fallback` when it is false. It has no look of its own and fetches nothing: you pass the entitlement decision.

## What FeatureGate supports

- Children, a fallback, or nothing while the decision loads.

## Where to use FeatureGate

- Around a feature that only some plans include, such as SSO settings or exports.
- Around a menu item or button that leads to such a feature.

Gates only change what the interface shows. Check the entitlement again on your server before doing the protected work.

## Importing FeatureGate

```tsx
import { FeatureGate, UpgradePrompt } from '@nozle-js/react'
```

## Rendering FeatureGate

```tsx
import { FeatureGate, UpgradePrompt } from '@nozle-js/react'

export function SsoSettings({ allowed }: { allowed: boolean }) {
  return (
    <FeatureGate allowed={allowed} fallback={<UpgradePrompt text="SSO needs the Scale plan" />}>
      <form>{/* SSO settings */}</form>
    </FeatureGate>
  )
}
```

## Using live data

[`useEntitlement(featureCode)`](/sdks/react/hooks#the-hooks) returns the customer's `can()` result through your `billingEndpoint`:

```tsx
import { FeatureGate, UpgradePrompt, useEntitlement } from '@nozle-js/react'

export function Exports() {
  const entitlement = useEntitlement('data_exports')
  return (
    <FeatureGate
      allowed={entitlement.data?.allowed ?? false}
      loading={entitlement.isPending}
      fallback={<UpgradePrompt planName="Pro" />}
    >
      <button type="button">Export CSV</button>
    </FeatureGate>
  )
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `allowed` | `boolean` | required | `true` renders `children`; `false` renders `fallback`. |
| `children` | `ReactNode` | required | The protected content. |
| `fallback` | `ReactNode` | `null` | Rendered when `allowed` is false. |
| `loading` | `boolean` | `false` | Renders nothing while true, so the fallback does not flash before the decision arrives. |

`FeatureGate` takes no `appearance`; style the fallback you pass.

`LockedOverlay` shows a blurred, non-interactive preview of its children with an [`UpgradePrompt`](/sdks/react/components/upgrade-prompt) on top. When `locked` is false it renders the children as they are.

## What LockedOverlay supports

- A 4px blur on the children, with clicks, selection and screen readers kept out of them.
- A panel over the content in the theme's background colour, with the upgrade message and button.
- No wrapper at all when unlocked.

## Where to use LockedOverlay

- A dashboard widget or report that a higher plan unlocks, so customers see what they would get.
- A settings panel available on another plan.

The blurred content is still in the page. Do not put data the customer must not see inside it, and enforce access on your server.

## Importing LockedOverlay

```tsx
import { LockedOverlay } from '@nozle-js/react'
```

## Rendering LockedOverlay

```tsx
import { LockedOverlay } from '@nozle-js/react'

export function AnalyticsPreview({ locked, openPlans }: { locked: boolean; openPlans: () => void }) {
  return (
    <LockedOverlay locked={locked} upgradePlanName="Scale" onUpgrade={openPlans}>
      <div style={{ padding: 24 }}>
        <strong>Advanced analytics</strong>
        <p>Revenue by cohort, retention curves and exports.</p>
      </div>
    </LockedOverlay>
  )
}
```

## Using live data

Lock it from the customer's entitlement with [`useEntitlement`](/sdks/react/hooks#the-hooks):

```tsx
import { LockedOverlay, useEntitlement } from '@nozle-js/react'

export function CohortReport() {
  const { data } = useEntitlement('advanced_analytics')
  return (
    <LockedOverlay locked={!data?.allowed} upgradePlanName="Scale" onUpgrade={() => window.location.assign('/plans')}>
      <section>{/* Sample report with placeholder data */}</section>
    </LockedOverlay>
  )
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `locked` | `boolean` | required | `true` blurs the children and shows the prompt; `false` renders the children only. |
| `children` | `ReactNode` | required | The content to preview. |
| `upgradePlanName` | `string` | none | Passed to `UpgradePrompt` as `planName`: "Upgrade to &lt;plan&gt; to access this feature". |
| `upgradeText` | `string` | `UpgradePrompt`'s default | Passed to `UpgradePrompt` as `text`, used when `upgradePlanName` is not set. |
| `onUpgrade` | `() => void` | Opens `/upgrade` | Called when "Upgrade" is clicked. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides, also passed to the prompt. See [Appearance](/sdks/react/styling). |

The root is an `inline-block`, sized by its children. The panel is a `role="dialog"` labelled "Feature locked — upgrade required".

### Appearance elements

`lockedOverlay` (root), `lockedOverlay__panel`, and `upgradePrompt` for the prompt.

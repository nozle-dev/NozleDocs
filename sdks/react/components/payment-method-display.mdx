`PaymentMethodDisplay` shows one saved payment method and an "Update Payment Method" button. You pass the card details; the component does not read them.

## What PaymentMethodDisplay supports

- Brand name, `•••• 1234` and `Expires MM/YY`.
- Readable names for `visa`, `mastercard`, `amex`, `discover`, `jcb`, `diners` and `unionpay`; another brand shows as sent.
- "No payment method on file." when there is none.
- An update button that calls your handler or opens a page.

## Where to use PaymentMethodDisplay

- The payment section of your billing settings page.
- Next to a past-due notice, so the customer can fix the card.

## Importing PaymentMethodDisplay

```tsx
import { PaymentMethodDisplay, type PaymentMethod } from '@nozle-js/react'
```

## Rendering PaymentMethodDisplay

```tsx
import { PaymentMethodDisplay, type PaymentMethod } from '@nozle-js/react'

const card: PaymentMethod = { brand: 'visa', last4: '4242', expMonth: 8, expYear: 2029 }

export function SavedCard({ openUpdate }: { openUpdate: () => void }) {
  return <PaymentMethodDisplay paymentMethod={card} onUpdatePaymentMethod={openUpdate} />
}
```

## Using live data

No Nozle hook returns the saved payment method. Read it on your backend from your payment provider for the signed-in customer, and pass `brand`, `last4`, `expMonth` and `expYear`.

```tsx
import { useEffect, useState } from 'react'
import { PaymentMethodDisplay, type PaymentMethod } from '@nozle-js/react'

export function CardFromBackend() {
  const [card, setCard] = useState<PaymentMethod | undefined>()
  useEffect(() => {
    void fetch('/api/billing/payment-method')
      .then((response) => (response.ok ? response.json() : undefined))
      .then(setCard)
  }, [])
  return <PaymentMethodDisplay paymentMethod={card} updateHref="/settings/billing/card" />
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `paymentMethod` | `PaymentMethod` | none | `brand`, `last4`, `expMonth` and `expYear` of the card. Without it the component shows "No payment method on file." |
| `onUpdatePaymentMethod` | `() => void` | none | Called when "Update Payment Method" is clicked. |
| `updateHref` | `string` | `'/billing/update-payment'` | Without `onUpdatePaymentMethod`, the button opens this URL in the same window. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides. See [Appearance](/sdks/react/styling). |

### Appearance elements

`paymentMethod` (root).

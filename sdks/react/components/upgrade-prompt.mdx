`UpgradePrompt` shows a centered message and an "Upgrade" button.

**When to use**

- As `fallback` of [`FeatureGate`](/sdks/react/components/feature-gate), [`PlanGate`](/sdks/react/components/plan-gate) or [`UsageGate`](/sdks/react/components/usage-gate).
- In an empty state of a feature the customer's plan does not include.
- Over blurred content: it is the panel of [`LockedOverlay`](/sdks/react/components/locked-overlay).

## Usage

```tsx Imports
import { UpgradeModal, UpgradePrompt } from '@nozle-js/react'
import type { UpgradePromptProps } from '@nozle-js/react'
```

Pass a plan name and open your plans from `onUpgrade`. The prompt fetches nothing and shows what you pass.

```tsx components/sso-upsell.tsx
export function SsoUpsell({ openPlans }: { openPlans: () => void }) {
  return <UpgradePrompt planName="Pro" onUpgrade={openPlans} />
}
```

### What a click does

With `onUpgrade`, a click calls it and nothing else. Without it, the button sets `window.location.href` to `/upgrade`.

## Examples

### Plan name

`planName` shows "Upgrade to &lt;planName&gt; to access this feature".

<Frame>
  <img src="/images/react/components/upgrade-prompt/light.png" alt="UpgradePrompt reading Upgrade to Pro to access this feature, with an Upgrade button, light theme" width="293" />
</Frame>

```tsx
export function ProPrompt({ openPlans }: { openPlans: () => void }) {
  return <UpgradePrompt planName="Pro" onUpgrade={openPlans} />
}
```

### Your own text

Without `planName`, `text` is the message.

```tsx
export function LimitPrompt({ openPlans }: { openPlans: () => void }) {
  return <UpgradePrompt text="You used all 1,000 API calls this month" onUpgrade={openPlans} />
}
```

### Open an upgrade modal

Open your plan change flow from `onUpgrade`, for example an [`UpgradeModal`](/sdks/react/components/upgrade-modal):

```tsx
import { useState } from 'react'

export function UpgradeToScale() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <UpgradePrompt planName="Scale" onUpgrade={() => setOpen(true)} />
      <UpgradeModal isOpen={open} planCode="scale" onCancel={() => setOpen(false)} onCompleted={() => setOpen(false)} />
    </>
  )
}
```

## API reference

<ResponseField name="planName" type="string">
  Shows "Upgrade to &lt;planName&gt; to access this feature". Takes priority over `text`.
</ResponseField>

<ResponseField name="text" type="string" default="Upgrade to access this feature">
  The message when `planName` is not set.
</ResponseField>

<ResponseField name="onUpgrade" type="() => void">
  Fires when "Upgrade" is clicked. Defaults to opening `/upgrade`: without it the button sets `window.location.href` to `/upgrade`.
</ResponseField>

<ResponseField name="appearance" type="Appearance">
  Theme, variables and element overrides on top of the provider's. See [Appearance](/sdks/react/styling).
</ResponseField>

### States

`UpgradePrompt` has one state: the message and the "Upgrade" button.

`PlanCard` renders a single plan with its price, the lines read from the plan and a button. Use it when you lay out your pricing page yourself instead of using [`PricingTable`](/sdks/react/components/pricing-table).

## What PlanCard supports

- Name, description, price with its interval, and the plan's lines from `planFeatures`.
- A current-plan look with a disabled "Current Plan" button.
- A "Get Started" button that calls your `onSelect` with the plan code and return URL.
- The `card` and `panel` layouts of the theme.

## Where to use PlanCard

- A custom pricing grid, carousel or comparison page.
- A "recommended plan" box next to other content.
- An upgrade prompt that shows the plan the customer would move to.

## Importing PlanCard

```tsx
import { PlanCard, type CreateCheckoutInput, type PricingPlan } from '@nozle-js/react'
```

## Rendering PlanCard

```tsx
import { PlanCard, type CreateCheckoutInput, type PricingPlan } from '@nozle-js/react'

const pro: PricingPlan = {
  code: 'pro',
  name: 'Pro',
  amount_cents: 2900,
  amount_currency: 'USD',
  interval: 'monthly',
  description: 'For growing teams',
  entitlements: [
    { feature_type: 'metered', code: 'api_calls', name: 'API calls', usage_limit: 50000 },
    { feature_type: 'metered', code: 'seats', name: 'Seats', usage_limit: 10 },
  ],
  credit_grant_rules: [{ credit_system_code: 'ai_credits', amount: '500', interval: 'month' }],
}

export function ProCard({ currentPlanCode }: { currentPlanCode: string }) {
  const select = ({ planCode, returnUrl }: CreateCheckoutInput) => {
    window.location.assign(`/checkout?plan=${planCode}&return=${encodeURIComponent(returnUrl)}`)
  }
  return (
    <PlanCard
      plan={pro}
      isCurrent={currentPlanCode === pro.code}
      returnUrl="https://app.example.com/settings/billing"
      onSelect={select}
    />
  )
}
```

## Using live data

Read the plans with [`usePlans`](/sdks/react/hooks#useplans) inside `BillingProvider`, and start checkout with [`useCheckoutSession`](/sdks/react/hooks#usecheckoutsession), which calls the provider's `createCheckout`. The catalog may return `description: null`, which `PricingPlan` does not accept, so map it.

```tsx
import { useState } from 'react'
import { Checkout, PlanCard, useCheckoutSession, usePlans, type PricingPlan } from '@nozle-js/react'

export function PlanCards({ currentPlanCode }: { currentPlanCode: string }) {
  const { plans } = usePlans()
  const { fetchClientSecret } = useCheckoutSession()
  const [clientSecret, setClientSecret] = useState<string | null>(null)

  if (clientSecret) {
    return <Checkout clientSecret={clientSecret} publishableKey="pk_live_stripe..." />
  }
  return plans.map((plan) => {
    const card: PricingPlan = { ...plan, description: plan.description ?? undefined }
    return (
      <PlanCard
        key={plan.code}
        plan={card}
        isCurrent={plan.code === currentPlanCode}
        onSelect={({ planCode, returnUrl }) => void fetchClientSecret(planCode, returnUrl).then(setClientSecret)}
      />
    )
  })
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `plan` | `PricingPlan` | required | The plan to show: `code`, `name`, `amount_cents`, `amount_currency`, `interval`, and optional `description`, `entitlements`, `credit_grant_rules`, `charges`. |
| `isCurrent` | `boolean` | required | Shows the card as the customer's plan: a primary-colour border, `aria-current="true"`, and a disabled "Current Plan" button. |
| `features` | `string[]` | Lines from `planFeatures(plan)` | Replaces the lines read from the plan. |
| `onSelect` | `(input: CreateCheckoutInput) => void` | none | Called with `{ planCode, returnUrl }` when the "Get Started" button is clicked. Without it the card has no button. |
| `returnUrl` | `string` | The current URL | The `returnUrl` passed to `onSelect`. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides. See [Appearance](/sdks/react/styling). |

The price is formatted in the plan's currency, without decimals for whole amounts (`$29`, `$14.99`). The interval reads `month`, `year`, `week`, `quarter` or `6 months`; other intervals show as sent. The root has `data-testid="plan-card-<code>"`.

`PlanCard` does not fetch anything and does not show [Powered by Nozle](/sdks/react/components/powered-by-nozle).

### Appearance elements

`planCard` (root), `planCard__name`, `planCard__description`, `planCard__price`, `planCard__features`, `planCard__feature`, `planCard__cta`. In the [panel layout](/sdks/react/styling#plan-card-layout) also `planCard__header` and `planCard__badge`, which reads "Active" on the current plan.

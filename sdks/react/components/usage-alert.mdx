`UsageAlert` shows one warning per feature at or above a usage threshold, each with an "Upgrade" link and a dismiss button. It renders nothing when no feature is over the threshold.

## What UsageAlert supports

- One warning per feature: "You're approaching your &lt;feature&gt; limit (N%). Upgrade".
- A threshold you choose, 80% by default.
- Dismissing a warning for as long as the component stays mounted.

## Where to use UsageAlert

- The top of your app's main page or dashboard.
- Above a feature that is close to its limit.

## Importing UsageAlert

```tsx
import { UsageAlert, type UsageAlertFeature } from '@nozle-js/react'
```

## Rendering UsageAlert

```tsx
import { UsageAlert, type UsageAlertFeature } from '@nozle-js/react'

const features: UsageAlertFeature[] = [
  { key: 'seats', label: 'Seats', percentage: 90 },
  { key: 'storage', label: 'Storage', percentage: 98 },
  { key: 'api_calls', label: 'API calls', percentage: 40 },
]

export function Alerts() {
  return <UsageAlert features={features} threshold={80} upgradeHref="/settings/billing/plans" />
}
```

Only Seats and Storage show here; API calls is below the threshold.

## Using live data

Work out the percentage from the `used` and `limit` of [`useEntitlement`](/sdks/react/hooks#the-hooks):

```tsx
import { UsageAlert, useEntitlement, type UsageAlertFeature } from '@nozle-js/react'

export function SeatsAlert() {
  const { data } = useEntitlement('seats')
  const features: UsageAlertFeature[] =
    data && data.limit ? [{ key: 'seats', label: 'Seats', percentage: ((data.used ?? 0) / data.limit) * 100 }] : []
  return <UsageAlert features={features} />
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `features` | `UsageAlertFeature[]` | required | `{ key, label, percentage }` per feature. The percentage is rounded in the text. |
| `threshold` | `number` | `80` | A feature at or above this percentage shows a warning. |
| `upgradeHref` | `string` | `'/plans'` | Where the "Upgrade" link goes. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides. See [Appearance](/sdks/react/styling). |

Dismissed warnings are kept in component state, keyed by `key`; they come back when the component mounts again.

### Appearance elements

`usageAlert` (root), `usageAlert__dismiss` (the × button).

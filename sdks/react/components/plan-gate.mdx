`PlanGate` renders its children when `currentPlan` is one of `allowedPlans`, and `fallback` otherwise.

**When to use**

- Around a section sold as part of higher plans, when no single entitlement describes it.
- When an allowlist of plan codes, compared exactly, decides access.

Prefer [`FeatureGate`](/sdks/react/components/feature-gate) with an entitlement when one exists: it keeps working when you add plans. Gates only change what the interface shows. Check access again on your server.

## Usage

```tsx
import { PlanGate, UpgradePrompt, type PlanGateProps } from '@nozle-js/react'
```

`PlanGate` has no look of its own and fetches nothing: you pass the customer's plan code.

```tsx components/team-settings.tsx
import { PlanGate, UpgradePrompt } from '@nozle-js/react'

export function TeamSettings({ planCode }: { planCode: string }) {
  return (
    <PlanGate currentPlan={planCode} allowedPlans={['pro', 'scale']} fallback={<UpgradePrompt planName="Pro" />}>
      <section>{/* Team settings */}</section>
    </PlanGate>
  )
}
```

## Data

The gate needs the customer's plan code as `currentPlan`. It has no loading state; render nothing yourself while the plan loads.

### Live data

Take the plan code from [`useSubscription`](/sdks/react/hooks#the-hooks):

```tsx
import { PlanGate, UpgradePrompt, useSubscription } from '@nozle-js/react'

export function Analytics() {
  const { data, isPending } = useSubscription()
  if (isPending) return null
  return (
    <PlanGate
      currentPlan={data?.subscription?.plan_code ?? ''}
      allowedPlans={['pro', 'scale']}
      fallback={<UpgradePrompt planName="Pro" />}
    >
      <div>{/* Analytics */}</div>
    </PlanGate>
  )
}
```

```tsx
import { PlanGate, UpgradePrompt } from '@nozle-js/react'

export function AuditLog({ planCode, openPlans }: { planCode: string; openPlans: () => void }) {
  return (
    <PlanGate currentPlan={planCode} allowedPlans={['scale']} fallback={<UpgradePrompt planName="Scale" onUpgrade={openPlans} />}>
      <section>{/* Audit log */}</section>
    </PlanGate>
  )
}
```

## API reference

<ResponseField name="currentPlan" type="string" required>
  The customer's plan code.
</ResponseField>

<ResponseField name="allowedPlans" type="string[]" required>
  Plan codes that may see `children`, compared exactly.
</ResponseField>

<ResponseField name="children" type="ReactNode" required>
  The plan-gated content.
</ResponseField>

<ResponseField name="fallback" type="ReactNode" default={null}>
  Rendered for any plan not in `allowedPlans`.
</ResponseField>

### States

| State | What shows |
|---|---|
| `currentPlan` in `allowedPlans` | `children`. |
| Any other plan | `fallback`, or nothing without one. |

`PlanGate` has no loading state.

### Appearance

`PlanGate` takes no `appearance` and has no element keys; style the fallback you pass.

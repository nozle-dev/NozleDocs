title: "PlanGate"
description: "Shows content only when the customer's plan is in a list of plans."
keywords: ["plan gate", "access control", "react"]
---

`PlanGate` renders its children when `currentPlan` is one of `allowedPlans`, and `fallback` otherwise. It has no look of its own and fetches nothing.

## What PlanGate supports

- An allowlist of plan codes, compared exactly.
- A fallback for every other plan.

## Where to use PlanGate

- Around a section sold as part of higher plans, when no single entitlement describes it.
- Prefer [`FeatureGate`](/sdks/react/components/feature-gate) with an entitlement when one exists: it keeps working when you add plans.

Gates only change what the interface shows. Check access again on your server.

## Importing PlanGate

```tsx
import { PlanGate, UpgradePrompt } from '@nozle-js/react'
```

## Rendering PlanGate

```tsx
import { PlanGate, UpgradePrompt } from '@nozle-js/react'

export function TeamSettings({ planCode }: { planCode: string }) {
  return (
    <PlanGate currentPlan={planCode} allowedPlans={['pro', 'scale']} fallback={<UpgradePrompt planName="Pro" />}>
      <section>{/* Team settings */}</section>
    </PlanGate>
  )
}
```

## Using live data

Take the plan code from [`useSubscription`](/sdks/react/hooks#the-hooks):

```tsx
import { PlanGate, UpgradePrompt, useSubscription } from '@nozle-js/react'

export function Analytics() {
  const { data, isPending } = useSubscription()
  if (isPending) return null
  return (
    <PlanGate
      currentPlan={data?.subscription?.plan_code ?? ''}
      allowedPlans={['pro', 'scale']}
      fallback={<UpgradePrompt planName="Pro" />}
    >
      <div>{/* Analytics */}</div>
    </PlanGate>
  )
}
```

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `currentPlan` | `string` | required | The customer's plan code. |
| `allowedPlans` | `string[]` | required | Plan codes that may see `children`. |
| `children` | `ReactNode` | required | The plan-gated content. |
| `fallback` | `ReactNode` | `null` | Rendered for any plan not in `allowedPlans`. |

`PlanGate` has no loading state and no `appearance`; render nothing yourself while the plan loads.

`PlanBadge` shows a plan name as a pill, coloured by one of four tiers and your theme.

**When to use**

- Next to the account or workspace name in your app's header or menu.
- In a team or customer list.
- On a feature that needs a higher plan.

## Usage

```tsx
import { PlanBadge, type PlanBadgeProps } from '@nozle-js/react'
```

Pass any text as `plan` and pick a `tier` for the colour:

```tsx components/account-menu.tsx
import { PlanBadge } from '@nozle-js/react'

export function AccountMenu() {
  return (
    <span>
      Acme Inc. <PlanBadge plan="Pro" tier="pro" />
    </span>
  )
}
```

The label uses the theme's small label font, so themes with uppercase labels show it in capitals.

## Data

The badge needs only a label and a tier; it does not read or know your plans.

### Live data

Take the plan name from [`useSubscription`](/sdks/react/hooks#the-hooks) and choose the tier from the plan code yourself:

```tsx
import { PlanBadge, useSubscription, type PlanBadgeProps } from '@nozle-js/react'

const tiers: Record<string, PlanBadgeProps['tier']> = { free: 'free', pro: 'pro', scale: 'enterprise' }

export function AccountPlan() {
  const { data } = useSubscription()
  const plan = data?.subscription?.plan
  if (!plan) return null
  return <PlanBadge plan={plan.name} tier={tiers[plan.code] ?? 'free'} />
}
```

## Examples

### Tiers

The four tiers: `free` (muted), `starter` (tinted primary), `pro` (primary) and `enterprise` (accent).

```tsx
import { PlanBadge } from '@nozle-js/react'

export function Badges() {
  return (
    <>
      <PlanBadge plan="Free" tier="free" />
      <PlanBadge plan="Starter" tier="starter" />
      <PlanBadge plan="Pro" tier="pro" />
      <PlanBadge plan="Enterprise" tier="enterprise" />
    </>
  )
}
```

## API reference

<ResponseField name="plan" type="string" required>
  The text of the badge.
</ResponseField>

<ResponseField name="tier" type="'free' | 'starter' | 'pro' | 'enterprise'" default="free">
  The colour: `free` uses `colorMuted` with a border, `starter` a tint of `colorPrimary`, `pro` `colorPrimary`, `enterprise` `colorAccent`.
</ResponseField>

<ResponseField name="appearance" type="Appearance">
  Theme, variables and element overrides on top of the provider's. See [Appearance](/sdks/react/styling).
</ResponseField>

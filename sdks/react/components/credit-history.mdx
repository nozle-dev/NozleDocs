`CreditHistory` lists credit operations as a table: when, type, feature, credits and status.

## What CreditHistory supports

- One row per operation, with readable types: Used, Granted, Adjustment, Expired, Revoked, Refunded, Transfer.
- Denied and reversed operations in muted text.
- A "Load more" button for paging.
- Loading, error and empty states.

## Where to use CreditHistory

- Below [`CreditBalance`](/sdks/react/components/credit-balance) in your billing settings.
- A support or audit view of a customer's credit activity.

## Importing CreditHistory

```tsx
import { CreditHistory, type CreditOperationData } from '@nozle-js/react'
```

## Rendering CreditHistory

```tsx
import { CreditHistory, type CreditOperationData } from '@nozle-js/react'

const operations: CreditOperationData[] = [
  { id: 'op_1', type: 'consume', status: 'succeeded', credit_amount: '-12', feature_code: 'ai_chat', occurred_at: '2026-10-16T08:40:00Z' },
  { id: 'op_2', type: 'grant', status: 'succeeded', credit_amount: '500', feature_code: null, occurred_at: '2026-10-01T00:00:00Z' },
  { id: 'op_3', type: 'consume', status: 'denied', credit_amount: '-900', feature_code: 'ai_video', occurred_at: '2026-09-28T11:12:00Z' },
]

export function Activity({ loadMore }: { loadMore: () => void }) {
  return <CreditHistory operations={operations} hasMore onLoadMore={loadMore} />
}
```

## Using live data

[`useCreditHistory({ creditSystemCode?, limit? })`](/sdks/react/hooks#the-hooks) reads the signed-in customer's operations a page at a time through your `billingEndpoint`. `operations` holds every loaded page.

```tsx
import { CreditHistory, useCreditHistory } from '@nozle-js/react'

export function LiveActivity() {
  const history = useCreditHistory({ creditSystemCode: 'ai_credits', limit: 20 })
  return (
    <CreditHistory
      operations={history.operations}
      hasMore={history.hasNextPage}
      onLoadMore={() => void history.fetchNextPage()}
      isLoading={history.isPending || history.isFetchingNextPage}
      error={history.error}
    />
  )
}
```

Without the hooks, pass the SDK's `credits.operations` page and fetch the next page with its `next_cursor`.

## Options

| Prop | Type | Default | What it does |
|---|---|---|---|
| `operations` | `CreditOperationData[]` | `[]` | `id`, `type`, `status`, `credit_amount`, `feature_code` and `occurred_at` of each operation. |
| `hasMore` | `boolean` | `false` | With `onLoadMore`, shows a "Load more" button under the table. |
| `onLoadMore` | `() => void` | none | Called when "Load more" is clicked. |
| `isLoading` | `boolean` | `false` | With no operations, shows a loading placeholder. With operations, the button reads "Loading…" and is disabled. |
| `error` | `Error`, `string` or `null` | `null` | Shows the message as an alert instead of the table. |
| `emptyMessage` | `string` | `'No credit activity yet.'` | Shown when there are no operations. |
| `appearance` | `Appearance` | The provider's | Theme, variables and element overrides. See [Appearance](/sdks/react/styling). |

Times show in `en-US` in the browser's time zone ("Oct 16, 2026, 8:40 AM"). An operation without a feature shows "—". A wide table scrolls sideways inside its frame.

### Appearance elements

`creditHistory` (root), `creditHistory__table`, `creditHistory__row`.

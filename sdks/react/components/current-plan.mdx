`CurrentPlan` shows the customer's subscription in one card, read through your `billingEndpoint` or from data you pass. From React `0.11.0`.

**When to use**

- The top of your billing settings page.
- A dashboard card that links to plan changes or the billing portal.
- Showing usage against the plan's metered limits next to the plan itself.
- Warning the customer about an overdue invoice or a nearly used limit.

## Usage

```tsx Imports
import { BillingProvider, CurrentPlan, currentPlanMeters, usePlans, useSubscription, useUsage } from '@nozle-js/react'
import type { BillingSubscription, CurrentPlanDetail, UsageDashboardFeature } from '@nozle-js/react'
```

Inside a `BillingProvider` with `billingEndpoint`, the card reads the subscription, the plan's limits and this period's usage itself:

```tsx app/settings/billing/page.tsx
'use client'

export default function BillingSettings() {
  return (
    <BillingProvider publishableKey="pk_live_..." billingEndpoint="/api/nozle">
      <CurrentPlan actions={<a href="/settings/billing/portal">Manage billing</a>} />
    </BillingProvider>
  )
}
```

The card shows the plan name, a status label, the price and interval, "Changes to &lt;plan&gt; on &lt;date&gt;" for a scheduled change, and one meter per metered limit, filled with this period's usage.

## Data

Pass `subscription` (the shape `useSubscription` returns) and `usage` to render your own data:

```tsx
const subscription: BillingSubscription = {
  subscription: {
    external_id: 'sub_123',
    plan_code: 'pro',
    status: 'active',
    ending_at: null,
    plan: { code: 'pro', name: 'Pro', amount_cents: 2900, currency: 'USD', interval: 'monthly' },
  },
  pending_change: { plan_code: 'scale', name: 'Scale', effective_at: '2026-11-01T00:00:00Z' },
  past_due: false,
}

const usage: UsageDashboardFeature[] = [{ key: 'api_calls', label: 'API calls', used: 41200, limit: 50000 }]

export function PlanSummary() {
  return <CurrentPlan subscription={subscription} usage={usage} />
}
```

### Live data

Leave `subscription` out and, inside a `BillingProvider` with `billingEndpoint`, `CurrentPlan` reads:

- the subscription with [`useSubscription`](/sdks/react/hooks#the-hooks),
- the plan's metered limits from the public catalog with `usePlans`,
- this period's units with `useUsage`, joined to the limits by feature code.

Serve `billingEndpoint` with `createBillingHandler` from `@nozle-js/node`; see [Serve the hooks from your backend](/sdks/react/hooks#serve-the-hooks-from-your-backend).

<Note>
Without `subscription`, `CurrentPlan` needs `BillingProvider` with `billingEndpoint`, or it throws "Billing hooks need BillingProvider billingEndpoint, a backend route served by createBillingHandler".
</Note>

### Meters from your own data

`currentPlanMeters(entitlements, usage)` joins a plan's metered entitlements with a period's `charges_usage` and returns `usage` rows:

```tsx
export function PlanWithMeters() {
  const subscription = useSubscription()
  const { plans } = usePlans()
  const usage = useUsage()
  const plan = plans.find((entry) => entry.code === subscription.data?.subscription?.plan_code)
  return (
    <CurrentPlan
      subscription={subscription.data ?? null}
      usage={currentPlanMeters(plan?.entitlements, usage.data)}
      isLoading={subscription.isPending}
      error={subscription.error}
    />
  )
}
```

### Loading, empty and error

`isLoading` shows a placeholder, `subscription={null}` shows `emptyMessage`, and `error` shows its message as an alert.

## API reference

<ResponseField name="subscription" type="BillingSubscription | null">
  The subscription, plan, `ending_at`, scheduled change and `past_due`. `null` shows the empty message. Defaults to the subscription read through `billingEndpoint`.
</ResponseField>

<ResponseField name="usage" type="UsageDashboardFeature[]">
  One meter per row: `{ key, label, used, limit }`. `limit: null` shows "Unlimited". Each meter is labelled "&lt;label&gt; used this period". Defaults to the plan's metered limits joined with this period's units.
</ResponseField>

<ResponseField name="details" type="CurrentPlanDetail[]">
  Extra `{ label, value }` rows under the meters, for example a renewal date. `value` can be any React node.
</ResponseField>

<ResponseField name="actions" type="ReactNode">
  Shown on the right of the header, for example a link to the billing portal.
</ResponseField>

<ResponseField name="warningPercent" type="number | null" default={80}>
  A meter at or above this percentage shows "You have used N% of the &lt;label&gt; included in &lt;plan&gt;." `null` turns these notices off.
</ResponseField>

<ResponseField name="pastDueMessage" type="string" default="A payment is overdue. Pay the open invoice to keep your plan active.">
  Shown as an alert when `past_due` is true.
</ResponseField>

<ResponseField name="title" type="string" default="Current plan">
  The header text.
</ResponseField>

<ResponseField name="emptyMessage" type="string" default="No active plan.">
  Shown when there is no subscription.
</ResponseField>

<ResponseField name="isLoading" type="boolean" default={false}>
  Shows a loading placeholder.
</ResponseField>

<ResponseField name="error" type="Error | string | null" default={null}>
  Shows the message as an alert.
</ResponseField>

<ResponseField name="locale" type="string" default="en-US">
  Formats the dates.
</ResponseField>

<ResponseField name="appearance" type="Appearance">
  Theme, variables and element overrides on top of the provider's. See [Appearance](/sdks/react/styling).
</ResponseField>

### States

| State | What shows |
|---|---|
| Loading | A loading placeholder. |
| No subscription | `emptyMessage`, "No active plan." by default. |
| Error | The error message as an alert. |
| `past_due` | `pastDueMessage` as an alert. |
| Meter at or above `warningPercent` | "You have used N% of the &lt;label&gt; included in &lt;plan&gt;." |

The status label depends on the subscription:

| Subscription | Label | Colour |
|---|---|---|
| `active`, no `ending_at` | Active | Success |
| `ending_at` set | Ends &lt;date&gt; | Warning |
| `pending` | Pending | Warning |
| `incomplete` | Awaiting payment | Warning |
| `canceled` | Canceled | Muted |
| `terminated` | Ended | Muted |

Another status is shown as sent.

The card shows [Powered by Nozle](/sdks/react/components/powered-by-nozle).

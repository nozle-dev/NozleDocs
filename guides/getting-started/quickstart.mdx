<Steps>

<Step>
## Create your Nozle account

Sign up at [app.nozle.dev](https://app.nozle.dev/signup) and create your first workspace.
</Step>

<Step>
## Get your API keys

From the dashboard, navigate to **Settings > API Keys**. Create the key types your integration needs:

| Key prefix | Purpose | Use in |
|------------|---------|--------|
| `pk_` | Publishable key | Public plan catalog only |
| `sk_` | Secret key | Server-side only (Node.js, Python, Go) |

<Warning>
Never expose your `sk_` secret key in client-side code. Use `pk_` only for public pricing and route every customer operation through your authenticated backend.
</Warning>
</Step>

<Step>
## Initialize the client

Set `NOZLE_SECRET_KEY` in your backend environment to your restricted `sk_` key, then create a Nozle client.

<Tabs items={['Node.js', 'Python', 'Go']}>
<Tab value="Node.js">
```ts title="nozle.ts"
import { Nozle } from '@nozle-js/node';

const nozle = new Nozle({
  apiKey: process.env.NOZLE_SECRET_KEY!,
  baseUrl: 'https://api.nozle.app/engine',
  eventsUrl: 'https://api.nozle.app/core',
});
```
</Tab>
<Tab value="Python">
```python title="nozle_client.py"
import os
from nozle import Nozle

nozle = Nozle(
    api_key=os.environ["NOZLE_SECRET_KEY"],
    base_url="https://api.nozle.app/engine",
    events_url="https://api.nozle.app/core",
)
```
</Tab>
<Tab value="Go">
```go title="nozle_client.go"
import (
  "os"
  nozle "github.com/nozle-dev/nozle-go"
)

client := nozle.New(os.Getenv("NOZLE_SECRET_KEY"))
```
</Tab>
</Tabs>
</Step>

<Step>
## Create the feature, plan, customer and subscription

Before sending an event, create a **metered Feature** with code `api_calls` in the dashboard. Add it to a **free plan** with code `quickstart_free`, using count aggregation and a limit of 10,000. Create a customer with external ID `customer_123` and activate a subscription to that plan. See [plans](/guides/billing/plans) and [subscriptions](/guides/billing/subscriptions) for the configuration steps.

Use the same Feature code, customer ID and subscription in the calls below. A placeholder customer without an active subscription cannot complete this quickstart. If the customer has multiple active subscriptions, pass the target external subscription ID explicitly using the SDK's [event options](/sdks/node/tracking-events).

This free count-based example does not charge a payment method or configure cost rating. The optional `tokens` metadata does not change the count: each unique event increments usage by one.
</Step>

<Step>
## Track your first event

Send a billable event with metadata. Nozle automatically resolves the customer's active subscription.

<Tabs items={['Node.js', 'Python', 'Go']}>
<Tab value="Node.js">
```ts
await nozle.track('customer_123', 'api_calls', {
  model: 'example-model',
  tokens: 1500,
});
```
</Tab>
<Tab value="Python">
```python
nozle.track("customer_123", "api_calls", {
    "model": "example-model",
    "tokens": 1500,
})
```
</Tab>
<Tab value="Go">
```go
err := client.Track(ctx, nozle.TrackParams{
  CustomerID: "customer_123",
  Event: "api_calls",
  Metadata: map[string]any{"model": "example-model", "tokens": 1500},
})
if err != nil { return err }
```
</Tab>
</Tabs>

Events are matched against your Feature definitions. For this count-based example, wait for asynchronous processing, then expect `used: 1`, `limit: 10000` and `remaining: 9999`. To meter token quantities instead, configure a separate sum-based Feature with `tokens` as its aggregation property.
</Step>

<Step>
## Check entitlements

Before executing an expensive operation, check whether the customer still has capacity on their plan.

<Tabs items={['Node.js', 'Python', 'Go']}>
<Tab value="Node.js">
```ts
const result = await nozle.can('customer_123', 'api_calls');
// {
//   allowed: true,
//   remaining: 9999,
//   limit: 10000,
//   used: 1
// }

if (!result.allowed) {
  throw new Error('Usage limit reached — upgrade your plan');
}
```
</Tab>
<Tab value="Python">
```python
result = nozle.can("customer_123", "api_calls")
# {
#   "allowed": True,
#   "remaining": 9999,
#   "limit": 10000,
#   "used": 1
# }

if not result["allowed"]:
    raise Exception("Usage limit reached — upgrade your plan")
```
</Tab>
<Tab value="Go">
```go
result, err := client.Can(ctx, "customer_123", "api_calls")
if err != nil { return err }
if !result.Allowed { return errors.New("usage limit reached — upgrade your plan") }
```
</Tab>
</Tabs>

The response includes `remaining`, `limit`, and `used` fields so you can show usage progress in your UI. Event processing is asynchronous; an immediate read may still show the earlier count. `can()` is a point-in-time check and does not reserve quota. Handle dependency errors as unavailable decisions, and read the [production integration checklist](/guides/getting-started/production-readiness) before accepting customer traffic.
</Step>

<Step>
## Add React billing components

Install the React SDK to get pre-built billing UI components.

```bash
npm install @nozle-js/react
```

Use a publishable key for public pricing. Provide a callback that calls your own authenticated backend for checkout:

```tsx title="app/providers.tsx"
import { BillingProvider, PricingTable } from '@nozle-js/react';

export function Providers({ csrfToken }: { csrfToken: string }) {
  return (
    <BillingProvider
      publishableKey="pk_..."
      createCheckout={async ({ planCode, returnUrl }) => {
        const response = await fetch('/api/billing/checkout', {
          method: 'POST',
          credentials: 'include',
          headers: {'Content-Type': 'application/json', 'X-CSRF-Token': csrfToken},
          body: JSON.stringify({planCode, returnUrl}),
        })
        if (!response.ok) throw new Error('Checkout failed')
        return response.json()
      }}
    >
      <PricingTable returnUrl={window.location.href} />
    </BillingProvider>
  );
}
```

Your backend authenticates the user, derives their Nozle customer, validates the plan and return URL, and calls Nozle with a restricted secret key.
</Step>

<Step>
## Show a pricing table and checkout

Drop in a `PricingTable` to display plans. Its CTA invokes the merchant callback configured above.

```tsx title="app/pricing/page.tsx"
import { PricingTable } from '@nozle-js/react';

export default function PricingPage() {
  return (
    <div>
      <h1>Choose your plan</h1>
      <PricingTable returnUrl={window.location.href} />
    </div>
  );
}
```

Fetch customer entitlements from your backend and pass the result into the presentational `FeatureGate`:

```tsx
import { FeatureGate } from '@nozle-js/react';

function AiFeature({ allowed }: { allowed: boolean }) {
  return <FeatureGate allowed={allowed} fallback={<p>Upgrade to continue.</p>}>AI feature</FeatureGate>;
}
```
</Step>

## Nozle Cloud

Nozle Cloud, at [app.nozle.app](https://app.nozle.app), is the only supported way to run Nozle in production. It includes:

- Margin intelligence and cost model analytics
- Backend entitlement checks with managed caching
- Stripe and Razorpay checkout
- Full SDK support (React, Node.js, Python, Go)
- Automatic scaling, monitoring, and updates

No infrastructure to manage. Use the hosted dashboard to configure billing and credentials.

## Self-hosting

Nozle does not support self-hosting today, and a self-hosted instance cannot connect to Nozle Cloud: no connector exists. The compose file in the Core repository runs the upstream open-source billing engine without Nozle features. See [Self-Hosting with Docker](/guides/self-hosting/docker).

title: Event Pipeline
description: How usage events move from your application into billing and margin reporting
---

Usage billing starts with an application-owned event. Each logical event should have a stable transaction ID, a customer, a Feature code, and the properties required by that metric.

## 1. Track from your backend

<CodeGroup>
```ts Node.js
import { Nozle } from '@nozle-js/node'
```
```python Python
from nozle import Nozle
```
```go Go
import nozle "github.com/nozle-dev/nozle-go"
```
</CodeGroup>

```ts title="Node.js"
const nozle = new Nozle({
  apiKey: process.env.NOZLE_SECRET_KEY!,
})

await nozle.track(
  'customer_123',
  'api_calls',
  { model: 'example-model', tokens: 1_500 },
  {
    subscriptionId: 'subscription_123',
    transactionId: 'request_0183f',
    timestamp: '2026-08-04T10:30:00Z',
  },
)
```

```python title="Python"
import os

nozle = Nozle(
    api_key=os.environ["NOZLE_SECRET_KEY"],
)

nozle.track(
    "customer_123",
    "api_calls",
    metadata={"model": "example-model", "tokens": 1_500},
    subscription_id="subscription_123",
    transaction_id="request_0183f",
    timestamp="2026-08-04T10:30:00Z",
)
```

```go title="Go"
client := nozle.New(os.Getenv("NOZLE_SECRET_KEY"))
err := client.Track(ctx, nozle.TrackParams{
  CustomerID: "customer_123",
  SubscriptionID: "subscription_123",
  Event: "api_calls",
  TransactionID: "request_0183f",
  Timestamp: "2026-08-04T10:30:00Z",
  Metadata: map[string]any{"model": "example-model", "tokens": 1500},
})
if err != nil { return err }
```

The Go SDK defaults to `https://api.nozle.app/engine` and `https://api.nozle.app/core`. Its `Track` method converts RFC3339 timestamps to the Unix-seconds form accepted by Engine. Event writes use the Engine base URL; subscription discovery uses Core.

## 2. Ingest and deduplicate

Nozle accepts the event through the Go Engine at `https://api.nozle.app/engine/api/v1/events`. Preserve both the transaction ID and event timestamp when retrying the same logical event. Deployments using the high-volume event store deduplicate on both values.

## 3. Aggregate usage

Metered Features define how properties are aggregated, including count, sum, maximum, and unique count. Property names must match the Feature configuration exactly.

## 4. Invoice and analyze

Aggregated usage becomes invoice charges according to the plan's pricing model. The same event metadata can feed cost models and margin reporting.

## Product-credit events

For actions that must be authorized and deducted from product credits, call `usage.track()` in Node.js, `usage.track()` in Python, or `TrackUsage()` in Go instead of sending a plain event. Nozle records the credit operation and queues the matching billing event in one durable workflow.

## Operational guidance

- Publish from a durable worker for high-volume or business-critical telemetry.
- Reuse the same transaction ID and timestamp on retries.
- Supply a subscription ID explicitly when a customer can have multiple active subscriptions (`subscriptionId` in Node.js, `subscription_id` in Python, or `SubscriptionID` in Go).
- Do not expect a plain event to reserve credits or synchronously update an invoice.

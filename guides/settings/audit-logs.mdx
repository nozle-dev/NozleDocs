---
title: Audit logs
description: See who changed your configuration and who signed in, filter the records, and export them.
---

Open **Settings** and choose **Audit logs**. The page has two views.

- **Configuration changes** lists every change made through the dashboard, the API, or the billing pipeline itself.
- **Sign-in activity** lists authentication, access and configuration events for the workspace. It appears only if your role can view the security log.

## Filters

| Filter | Use it to |
| --- | --- |
| Source | Show changes from the Dashboard, the API, or the System. |
| API key | Show changes made with one API key. |
| Result | Show only Succeeded or Failed changes. |
| Date | Limit the date range. |
| Person's email | Show one person's changes. |
| Activity type | Show one kind of change. |
| Resource type and Resource ID | Show changes to one kind of record, or one record. |
| Customer and Subscription external ID | Show changes tied to one customer or subscription. |

Every filter except **Result** runs on the server across all matching records. **Result** narrows only the rows on the current page.

## Details

Select a change to see who made it, the source, the API key, the resource and when it was recorded. A field-level diff shows each field's old and new value. Sensitive values are redacted.

## Export

**Export filtered CSV** exports every record that matches the current filters, not just the current page. The download is ready for 15 minutes. After that, run the export again.

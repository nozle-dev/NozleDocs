---
title: Create Credit Top-up Purchase
api: "POST https://api.nozle.app/engine/api/v1/credit-top-up-purchases"
description: Start checkout for a fixed product-credit package
---

Base URL: `https://api.nozle.app/engine/api/v1`.

**Auth:** secret key only. Publishable keys are rejected. `Idempotency-Key` is required.

```json
{
  "customer_id": "customer_123",
  "credit_system_code": "ai_credits",
  "top_up_package_code": "starter_pack"
}
```

The response returns the pending purchase snapshot and hosted `payment_url`. Navigate the same page to that URL. For a customer on [Stripe](/integrations/stripe#credit-top-ups), `payment_url` is a hosted Stripe Checkout page, and the customer must already be linked to a Stripe customer. For a customer on [Razorpay](/integrations/razorpay#credit-top-ups), `payment_url` is a Razorpay payment link and the package must be priced in INR.

<Warning>
Creating checkout does not grant credits. Credits are materialized only after Nozle records and validates a confirmed successful payment.
</Warning>

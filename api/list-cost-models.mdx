---
title: "List Cost Models"
api: "GET /cost-models"
---

List all cost models for the current organization.

<Warning>
This legacy endpoint does not return the new versioned Cost Sheets. Use the Cost Intelligence dashboard for new implementations.
</Warning>

**Auth:** `sk_` only

<Warning>
All cost model endpoints require a secret key (`sk_`). Publishable keys will receive a 403 Forbidden response.
</Warning>

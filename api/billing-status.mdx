---
title: "Billing Status"
api: "GET https://api.nozle.app/engine/api/v1/billing/status"
---

Base URL: `https://api.nozle.app/engine/api/v1`.

Get the plan of a customer's active subscription. If the customer has several active subscriptions, Nozle uses the one that started most recently.

**Auth:** secret key only. Publishable keys are always rejected.

<ParamField query="customer_id" type="string" required>
  External customer ID derived by the trusted merchant backend.
</ParamField>

### Response

```json
{
  "plan": "pro",
  "planName": "Pro",
  "status": "active",
  "interval": "monthly",
  "amount_cents": 4900,
  "currency": "USD"
}
```

<ResponseField name="plan" type="string" required>
  Plan code of the active subscription.
</ResponseField>

<ResponseField name="planName" type="string" required>
  The plan's display name. Falls back to the plan code when the plan has no name.
</ResponseField>

<ResponseField name="status" type="string" required>
  Always `active`. Only active subscriptions are read.
</ResponseField>

<ResponseField name="interval" type="string" required>
  The plan's billing interval: `weekly`, `monthly`, `yearly`, `quarterly` or `semiannual`.
</ResponseField>

<ResponseField name="amount_cents" type="integer" required>
  The plan's base amount, in the currency's smallest unit.
</ResponseField>

<ResponseField name="currency" type="string" required>
  The plan's currency.
</ResponseField>

### Errors

| Status | Meaning |
|--------|---------|
| `400` | `customer_id` is missing. |
| `404` | The customer has no active subscription, or the lookup failed. |

<Note>
  Also available as `GET /subscriptions/current` (alias).
</Note>

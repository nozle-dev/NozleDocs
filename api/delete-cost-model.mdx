---
title: "Delete Cost Model"
api: "DELETE /cost-models/{id}"
---

Delete a cost model by ID.

<Warning>
This legacy endpoint is retained only for rollback and cleanup. New Cost Intelligence configuration is versioned and is not managed through this route.
</Warning>

**Auth:** `sk_` only

<Warning>
All cost model endpoints require a secret key (`sk_`). Publishable keys will receive a 403 Forbidden response.
</Warning>

<ParamField path="id" type="string" required>
  Cost model ID
</ParamField>

---
title: Check Credit Usage
api: "POST https://api.nozle.app/engine/api/v1/usage/check"
description: Calculate an advisory credit decision without mutation
---

Base URL: `https://api.nozle.app/engine/api/v1`.

**Auth:** secret key only.

```json
{
  "customer_id": "customer_123",
  "feature_code": "agent_execution",
  "credit_system_code": "ai_credits",
  "properties": {},
  "occurred_at": "2026-07-20T12:00:00.750Z"
}
```

`occurred_at` is required and must be an RFC 3339 string with a time zone offset or `Z`. Unix seconds (as a string or a number), a date without a time, and a time without an offset return `400 invalid_request` with `occurred_at must be an RFC3339 timestamp`. The SDKs send the current time when you omit it.

A customer with more than one active subscription returns `422 active_subscription_ambiguous`. A time with no effective Credit System rate returns `422 credit_usage_configuration_invalid` (`no effective credit rate`).

The response includes `advisory: true`, exact `metric_amount`,
`credits_required`, the available balance, and the projected source
selection:

```json
{
  "advisory": true,
  "allowed": true,
  "metric_amount": "1",
  "credit_system": "ai_credits",
  "credits_required": "2",
  "available": "625",
  "projected_remaining": "623",
  "projected_deductions": [
    {
      "balance_source_id": "0f89...",
      "source_type": "subscription_grant",
      "amount": "2",
      "remaining": "373"
    }
  ]
}
```

Projected deductions follow the same deterministic expiry, priority, creation
time, and ID ordering as an authoritative consume, but no source or ledger row
is changed. Another request can spend credits before a later track call, so
this endpoint is not authorization to perform irreversible work.

---
title: "List Invoices"
api: "GET https://api.nozle.app/engine/api/v1/invoices"
---

Base URL: `https://api.nozle.app/engine/api/v1`.

List a customer's invoices, newest first. The response holds at most 50 invoices and has no pagination. It returns the invoices Core's API shows, other than drafts: `finalized`, `voided`, `failed` and `pending`. Invoices still being generated are not returned. Whether an invoice is paid is in `payment_status`, not in `status`. Only the live customer with this `customer_id` counts: a new customer that reuses a deleted customer's external ID does not see the deleted customer's invoices.

**Auth:** secret key only. Publishable keys are always rejected.

<ParamField query="customer_id" type="string" required>
  External customer ID derived by the trusted merchant backend.
</ParamField>

### Response

Returns an object with an `invoices` array. The array is empty when the customer has no invoices.

```json
{
  "invoices": [
    {
      "id": "invoice_uuid",
      "number": "ACME-202610-001",
      "status": "finalized",
      "payment_status": "succeeded",
      "invoice_type": "subscription",
      "amount_cents": 4900,
      "currency": "USD",
      "issuing_date": "2026-10-01",
      "payment_due_date": "2026-10-01",
      "created_at": "2026-10-01T00:00:05Z"
    }
  ]
}
```

| Field | Values |
| --- | --- |
| `status` | `finalized`, `voided`, `failed`, or `pending` |
| `payment_status` | `pending`, `succeeded` (paid), `failed`, or `unknown` |
| `invoice_type` | `subscription`, `add_on`, `credit`, `one_off`, `advance_charges`, `progressive_billing`, or `other` for a type Engine does not know |
| `amount_cents` | Invoice total, in the currency's smallest unit |
| `issuing_date`, `payment_due_date` | `YYYY-MM-DD`, or `null` |

A missing `customer_id` returns `400`. A database failure returns `500`.

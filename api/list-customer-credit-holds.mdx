---
title: List Customer Credit Holds
api: "GET https://api.nozle.app/engine/api/v1/customers/{customer_id}/credit-holds"
description: List a customer's newest credit holds, optionally by status
---

Base URL: `https://api.nozle.app/engine/api/v1`. Available from Engine 2.34.0.

**Auth:** secret key only. The key requires `credit_system:read`. Publishable keys are rejected.

```http
GET /customers/customer_123/credit-holds?status=held
Authorization: Bearer sk_nozle_...
```

Returns the customer's newest 100 credit holds, newest first, including the holds of its Entities. [Budget holds](/api/create-usage-hold#budget-holds) (Engine 2.34.0) are not listed; read one by ID with [Get a Credit Hold](/api/get-usage-hold). `status` is optional and is one of `held`, `denied`, `finalized`, `released` or `expired`; any other value returns `400 invalid_request`. `held` lists the holds that reserve credits now; `expired` also lists open holds past their expiry that the sweep has not marked yet.

```json
{
  "customer_id": "customer_123",
  "holds": [
    {
      "hold_id": "6f1d1c8e-5a43-4c0e-9d0b-2f1c9e7a4b10",
      "status": "held",
      "customer_id": "customer_123",
      "entity_id": "user_42",
      "feature_code": "agent_execution",
      "credit_system": "ai_credits",
      "pool_policy": "entity_then_customer",
      "metric_amount": "8000",
      "credits_required": "8",
      "credits_held": "8",
      "expires_at": "2026-10-31T12:10:00.912Z",
      "created_at": "2026-10-31T12:00:00.912Z",
      "resolved_at": null
    }
  ]
}
```

Each item has the fields of [Get a Credit Hold](/api/get-usage-hold#response). An unknown customer returns `404 customer_not_found`; a customer with no holds returns an empty `holds` list. A retryable read failure returns `503 credit_read_temporarily_unavailable` with `Retry-After`.
